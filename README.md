# Botellous

Juego de plataformas y acción en 2D hecho en Unity para PC y Android.

## Controles

| Acción | PC | Android |
|---|---|---|
| Andar | A / D | Botones táctiles de izquierda y derecha |
| Saltar | W | Botón de saltar |
| Atacar | Clic izquierdo | Botón de atacar |
| Recoger objetos / interactuar | Mantener E | Botón de interactuar |
| Pausa | Esc | Botón de pausa |
